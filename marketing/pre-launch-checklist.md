# Чек-лист перед публикацией — по каким параметрам проверять «Истории Веры»

Пять категорий: работоспособность, техника, контент, юридические требования сторов, безопасность.
ASO/тексты карточки/скриншоты — в `aso.md`/`post-release-plan.md`, здесь не повторяю.

---

## 1. Работоспособность (функциональность)

- [x] **Проверено (2026-07-23):** все 250 комбинаций (50 историй × 5 языков) открываются без единой
      ошибки в консоли и без единого битого файла — прогнано автоматически через playwright.
- [x] **Проверено (2026-07-23) — и это было НЕ проверено ни разу до сих пор:** `node test.js` раньше
      проверял только светлый путь (всегда первый вариант выбора). Дополнил тест — теперь для каждой из
      250 комбинаций проверяется ещё и **тёмный путь** (всегда последний вариант): доходит до финала,
      даёт отрицательный `faith`. Все 250 прошли. Тест теперь навсегда в `test.js`, будет ловить
      поломанные тёмные концовки при любых будущих правках контента.
- [x] **Проверено (2026-07-27):** озвучка переведена с ненадёжного браузерного Web Speech API на
      заранее записанные mp3-файлы (Google Cloud TTS, все 50×5 сцен) — прежний риск зависаний/обрывов
      голоса посреди фразы исчез вместе с самим механизмом, который его вызывал. Живьём проверено на
      Android-телефоне пользователя: звук, пауза/резюм, мьют, двойной тап для пропуска сцены,
      переключение языка — всё работает.
- [x] **Проверено (2026-07-23):** переключение светлой/тёмной темы во время истории — работает,
      ошибок не возникает (см. также отдельный большой раунд правок темы).
- [ ] Отметка «история пройдена» сохраняется и видна в меню после перезапуска приложения — логика
      в коде корректна (localStorage), но не перепроверялась именно «перезапуском» отдельно сейчас.
- [x] **Реальный Android-телефон — протестирован (2026-07-27), пусть пока только в браузере, не в
      Capacitor-сборке.** Прежний риск был специфичен именно для Android WebView + браузерного голоса
      — с готовыми mp3-файлами он не воспроизводится ни в браузере, ни в приложении. Сборку через
      Capacitor всё равно стоит один раз проверить вживую на Android при её появлении, но не из-за
      голоса — как общую подстраховку.

## 2. Техническая часть

- [x] **Проверено (2026-07-23):** ноль ошибок в консоли на всех 250 комбинациях история×язык.
- [x] **Проверено (2026-07-23):** ни одного 404 или другой ошибки загрузки ни на одном файле.
- [x] **Проверено (2026-07-23):** во время работы игры (загрузка + начало истории + смена темы) —
      **ноль сетевых запросов вовне** (только локальные `file://`). Это прямое подтверждение на уровне
      кода, что офлайн-работа возможна — но собранное через Capacitor приложение всё равно стоит
      перепроверить отдельно один раз вживую, это не стопроцентная замена реальному тесту.
- [ ] Скорость первой загрузки приемлема — самый тяжёлый файл `content-hi.js` (≈410КБ), у остальных
      языков меньше; для сайта это не критично, для встроенного в приложение бандла — тем более
      (грузится один раз при установке, не при каждом заходе). Не измерялось секундомером, но по объёму
      файлов рисков не видно.

## 4. Юридические требования сторов (важно — здесь нашёлся реальный пробел)

- [x] **Готово и задеплоено, обновлено (2026-07-27):** `privacy.html`, ссылка для сторов —
      **https://faithchoice.net/privacy.html**. Честно описывает реальную ситуацию: localStorage
      (язык/тема/звук/пройденные истории) не передаётся никуда, озвучка — заранее записанные mp3
      (Google Cloud TTS на этапе подготовки, ничего не уходит с устройства игрока в реальном времени —
      раздел переписан, старое упоминание браузерного Web Speech API убрано как устаревшее), никакой
      рекламы/трекинга, 17+. **Не забыть обновить**, если/когда добавите Cloudflare Analytics —
      появится реальный пункт про анонимную статистику посещений, которого пока честно нет.
- [ ] **Data Safety Form (Google Play) / App Privacy Details (App Store)** — отдельная анкета в личном
      кабинете разработчика о том, какие данные собирает приложение. Заполняется честно на основе той
      же политики конфиденциальности выше.
- [ ] Возрастной рейтинг в консоли разработчика выставлен в соответствии с реальным контентом (17+/
      Mature) — при заполнении анкеты рейтинга не занижать из-за того, что тема «духовная», содержание
      объективно тяжёлое.
- [ ] Открытый вопрос про закон о миссионерской/религиозной деятельности РФ — по-прежнему не подтверждён
      юристом (см. основной файл о статусе игры) — актуален прежде всего для рассылки писем организациям,
      не для самой публикации в сторе, но держать в уме.
