# Бриф: удлинение историй до 3:00 озвучки (реальные факты)

**ОБНОВЛЕНИЕ: content-ru.js теперь на 100% готов (все 50 историй ≥2340 симв. на обоих путях). НЕ трогайте
content-ru.js вообще — только читайте его как эталон. Вся оставшаяся работа — это ТОЛЬКО перевод уже
готового RU-текста в EN/ES/ZH/HI, не написание нового контента и не WebSearch (если перевод не может
уместиться в цель — считайте, что для zh это нормально при точном переводе, добавляйте по смыслу, не гадая
факты).**

## Контекст проекта
Сайт-игра «Истории Веры» / «Faith Choice» (faithchoice.net) — 50 отдельных интерактивных историй
по мотивам **реальных задокументированных христианских свидетельств**, на 5 языках (ru/en/es/zh/hi).
Игрок выбирает историю, идёт по сценам, в 2 точках делает выбор (тьма/свет), доходит до одного из
двух финалов. Персонажи — вымышленные имена, но сюжет и детали должны быть основаны на РЕАЛЬНОМ,
проверяемом человеке (задокументированном свидетельстве), а не на выдумке.

**Главное правило проекта, нарушать нельзя:** сначала находим конкретное реальное свидетельство →
потом пишем сюжет ИЗ его фактов. Никогда не наоборот (не придумываем сюжет и не подгоняем под него
факты). Если не уверены, кто реальный прототип персонажа — используйте WebSearch, чтобы найти и
проверить, не изобретайте.

## Задача
Обнаружено: большинство из 50 историй звучат заметно короче целевых 3:00 при озвучке (проверено по
модели символы/сек — см. ниже). Нужно **удлинить** истории реальными фактами (не водой, не общими
фразами) так, чтобы **и светлый, и тёмный путь** доходили минимум до целевой длины в символах.

**Модель скорости чтения:**
- ru/en/es/hi: 13 символов/сек → цель = **2340 символов** (сумма text всех сцен на пути).
- zh: 4.5 символов/сек (иероглиф ≈ слог, несёт больше смысла на символ) → цель = **810 символов**.

## Обязательное правило от пользователя проекта (дословно)
«При дополнении историй предпочтительно добавлять реальные факты — больше Бога». То есть новые
предложения должны быть (а) реальными, проверяемыми фактами о прототипе, и (б) по возможности
усиливать явное присутствие веры — молитву, чтение Писания, разговор с Богом, — а не просто
добавлять нейтральные биографические детали. Мало одного случайного упоминания «верующий» — нужна
видимая практика веры на протяжении истории.

## Как измерять (Node, из папки c:\Projects\game)
```js
const { Story } = require('./engine.js');
const { STORIES } = require('./content-ru.js'); // или content-<lang>.js
function pathChars(data, pickLast) {
  const story = new Story(data);
  let total = 0, scene = story.current(), steps = 0;
  while (steps < 100) {
    total += scene.text.length;
    if (scene.choices && scene.choices.length) scene = story.choose(pickLast ? scene.choices.length - 1 : 0);
    else if (scene.next != null) scene = story.advance();
    else break;
    steps++;
  }
  return total;
}
const light = pathChars(STORIES['KEY'], false);
const dark = pathChars(STORIES['KEY'], true);
console.log('light=', light, 'dark=', dark, 'min=', Math.min(light, dark));
```
**Важно:** нужно поднять и light, и dark путь — они частично расходятся (bridgeA/bridgeB, endLight/
endDark), добавления в общие сцены (intro/scene2/choice1) поднимают оба сразу, но обычно нужно ещё
точечно добавить в более короткую ветку отдельно. Проверяйте `Math.min(light, dark)` — именно оно
должно быть ≥ цели.

## Как редактировать
- Файлы: `c:\Projects\game\content-ru.js`, `content-en.js`, `content-es.js`, `content-zh.js`,
  `content-hi.js` — каждый оборачивает `window.Content.<lang> = { CHARACTERS, STORIES }`.
- Каждая история — набор сцен по ключам вида `<key>_intro`, `<key>_scene2`, `<key>_choice1`,
  `<key>_bridgeA`/`<key>_bridgeB` (или `<key>_bridgeCommon`, если веток нет), `<key>_choice2`,
  `<key>_endLight`, `<key>_endDark`. **Не меняйте структуру** (ключи сцен, `next`, `choices[].next`,
  `effects.faith`) — только текст `text:` внутри сцен, дописывая/расширяя существующие предложения.
- Порядок работы на КАЖДУЮ вашу историю:
  1. Прочитать текущий RU-текст истории целиком (все сцены).
  2. Определить реального прототипа (если не указан ниже явно или неясен из текста — WebSearch по
     деталям сюжета, который уже написан, чтобы найти исходное реальное свидетельство).
  3. Дописать в RU 3-6 предложений реальных фактов, распределяя по сценам естественно (не одним
     комком в одном месте) — с акцентом на молитву/веру, как просил пользователь.
  4. Измерить (скрипт выше). Если light или dark всё ещё < 2340 — добавить ещё, ЦЕЛЕНАПРАВЛЕННО в
     более короткую ветку.
  5. Когда RU готов — перенести ТЕ ЖЕ добавленные факты (перевод, не новые факты) в EN/ES/ZH/HI, в
     соответствующие сцены по тем же ключам. Тон/стиль/имена персонажа в каждом языке уже
     установлены в файле — сохраняйте их (не меняйте существующие имена персонажей).
  6. Для zh — если после перевода добавлений всё ещё не хватает до 810 симв на путь, можно
     добавить чуть больше деталей именно в zh (соразмерно), не обязательно 1:1 по числу символов с ru.
  7. `node --check content-<lang>.js` после каждого файла (синтаксис).
  8. В конце по своим историям — `node test.js` из `c:\Projects\game` должен остаться зелёным
     (полностью, для всех 250 комбинаций, не только ваших — если сломали что-то чужое, вероятно
     задели не тот ключ сцены).

## Стиль и качество — ориентир (уже сделано в этой сессии, см. как образец)
Персонаж Сергей (реальный прототип — Louis Zamperini, WWII): в RU уже было упоминание плена и
пыток, но ни слова о самом драматичном факте — крушении самолёта и 47 днях на плоту в океане.
Добавлено: сцена крушения и выживания на плоту (реальный, проверяемый факт), клятва Богу на плоту
«если Ты спасёшь меня, я буду служить Тебе всю жизнь» (молитва — усиление «Бога» в истории), попытка
молиться по ночам, которая не получается, деталь о том, что жена впервые в жизни помолилась
собственными словами, и в финале — реальный факт, что Zamperini позже летал в тюрьму к бывшим
охранникам лично их простить. Использованы файлы content-ru.js/content-en.js — посмотрите эти сцены
(`sergey_intro`, `sergey_choice2`, `sergey_endLight` и т.д.) как образец глубины и баланса
факт/вера.

## Важные уроки прошлых сессий (не повторять ошибки)
- **Не занимайте имя, уже занятое другим персонажем.** Полный список 50 игровых имён — в
  `CHARACTERS` внутри `content-ru.js`. Второстепенные имена (родственники, друзья) — сверяйте, что
  не совпадают с именем другого главного персонажа.
- **При замене имени в хинди — риск коллизии с обычным словом языка** (было с «Лена»/लेना = глагол
  «брать»). Если добавляете новое имя в hi-тексте — проверьте, не совпадает ли транслитерация с
  частым словом.
- **Не пишите сюжет «от темы»**, декорируя потом цитатами реального человека — это уже было ошибкой
  в прошлом и было полностью переписано. Сначала факт, потом сцена.
- **Логическая согласованность bridgeA/bridgeB:** сцена ПОСЛЕ развилки не должна содержать деталей,
  верных только для одной из веток.
- Не трогайте `CHARACTERS` (имена/цвета/иконки), только `STORIES`.
